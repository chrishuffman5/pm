# pm — example project

This folder is a **worked example** of the `pm` skill managing a real project: *itself*. The
PM tree under `example/pm/` documents how the `pm` Claude Code skill was designed, built,
tooled, validated, and prepared for open-source release — the same journey this repository
records in its own history.

It exists for two reasons:

1. **A live dashboard.** `example/pm/index.html` (and the per-node pages beside every
   `CLAUDE.md`) are generated by the skill's own `build-pm-html.ps1`. GitHub Pages serves
   them so anyone can click through a finished tree — epic → features → stories → tasks,
   with status rollups and timestamps — without installing anything.
2. **A reference shape.** It shows the exact folder layout, file templates, numbering, and
   status discipline a project gets when you run `/pm init` and then work it with
   `/pm plan` and `/pm`.

The "product" being managed here is the skill itself, so the features and stories map to the
real build phases: foundation & packaging, the lifecycle modes, the tooling, and validation
& release. Statuses are real — most of the work is `Done`; the release feature is still
`In progress`, which is why the dashboard shows partial completion.

Nothing here is a dependency of the skill; it's documentation. Regenerate the tracker after
editing any `CLAUDE.md` with:

```
pwsh -NoProfile -File example/pm/build-pm-html.ps1 -Path example/pm -ProjectName "pm — Claude Code skill"
```
